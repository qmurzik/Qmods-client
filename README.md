# AnixQ — iOS-клиент для Anixart

Нативное приложение на SwiftUI (iOS 16+) для просмотра аниме через API [Anixart](https://anixart.tv).
Неофициальный клиент: каталог, описания и видео отдаёт сам Anixart и его плееры (Kodik и др.).

## Возможности

- **Главная**: баннеры «Интересное», продолжить просмотр, последние обновления, обсуждаемое, популярное, топ.
- **Каталог**: сортировка (новые серии / рейтинг / популярное), фильтр по типу, статусу, годам и жанрам, бесконечная прокрутка.
- **Поиск** по названию с историей запросов.
- **Расписание** выхода серий по дням недели.
- **Страница тайтла**: постер, рейтинг, описание, жанры, студия, кадры, связанные релизы и рекомендации.
- **Просмотр**: выбор озвучки/субтитров → плеера → серии; встроенный плеер (WKWebView) с полноэкранным режимом,
  PiP, AirPlay, переключением на предыдущую/следующую серию.
- **История** просмотра и отметки просмотренных серий — локально, без аккаунта.
- **Аккаунт Anixart** (необязательно): вход, избранное, списки «Смотрю / В планах / Просмотрено / Отложено / Брошено».
- Автоматическое переключение на зеркала API (`api-s2.anixart.tv`, `api.anixsekai.com`), если основной хост недоступен.

## Структура

```
project.yml                  XcodeGen-описание проекта (.xcodeproj генерируется)
AnixQ/App                    точка входа, TabView, тема
AnixQ/Network                AnixartAPI (эндпоинты) + устойчивые к формату модели
AnixQ/Stores                 AuthStore (токен), HistoryStore (локальная история)
AnixQ/Views                  экраны: Home, Catalog, Search, Schedule, ReleaseDetail, Episodes, Player, Profile
.github/workflows            сборка неподписанного IPA на macOS-раннере GitHub Actions
```

## Как получить IPA

Сборка идёт в GitHub Actions (workflow **Build IPA**) на каждый push в ветку `claude/anixart-ios-app`:

1. Откройте вкладку **Actions** → последний запуск **Build IPA**.
2. Скачайте артефакт **AnixQ-ipa** (внутри `AnixQ.ipa`).
3. При пуше тега `v*` (например `v1.0.0`) IPA дополнительно прикрепляется к GitHub Release.

IPA **не подписан**. Установить его можно через:
- **AltStore / SideStore** или **Sideloadly** — переподпишут вашим Apple ID (бесплатный аккаунт: 7 дней, затем переустановка);
- **TrollStore** — на поддерживаемых версиях iOS, без переподписи;
- собственный сертификат разработчика (`zsign`, Xcode, etc.).

## Локальная сборка (macOS)

```bash
brew install xcodegen
xcodegen generate
open AnixQ.xcodeproj   # выбрать свою Team в Signing & Capabilities и запустить на устройстве
```
